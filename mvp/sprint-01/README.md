# 📦 MVP — Sprint 1

## 🎯 Objetivo

Criar um meio de captação de clientes simples que permita ao usuário
conhecer os cartões da DM e iniciar uma solicitação e escolher um dos cartões oferecidos.

## 💡 Solução

Desenvolver uma Landing Page simples e intuitiva, com formulário para
preenchimento dos dados do cliente e aplicação das regras iniciais de
pré-qualificação para seleção de um tipo de cartão.

A solução também deverá permitir a visualização do status da
qualificação e o encaminhamento do cliente para a seleção de loja e
tipo de cartão, considerando o estado informado e as opções disponíveis.

## ✅ Critérios de Aceitação

- A Landing Page deve apresentar uma estrutura simples e intuitiva.
- O cliente deve conseguir preencher os dados necessários para a solicitação.
- O sistema deve validar os campos obrigatórios do formulário.
- O sistema deve aplicar as regras de pré-qualificação definidas para a Sprint.
- O cliente deve visualizar o status correspondente à sua solicitação.
- O cliente pré-qualificado deve ser encaminhado para a seleção de tipo de cartão e loja, quando aplicável.
- O sistema deve apresentar apenas as lojas compatíveis com o estado ou CEP informado.
- O sistema deve apresentar os cartões disponíveis para a loja selecionada.

## 📊 Validação

A validação será realizada por meio de testes manuais da Landing Page,
verificando o preenchimento do formulário, a aplicação das regras de
pré-qualificação, a apresentação do status da solicitação e o
encaminhamento para a seleção de loja e cartão.

Os resultados dos testes serão registrados pela equipe e utilizados
para identificar possíveis ajustes antes do encerramento da Sprint.
